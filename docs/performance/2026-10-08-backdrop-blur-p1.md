# BackdropBlur P1 性能优化与复测 · 2026-10-08

## 实现

本轮在 [P0](2026-10-08-backdrop-blur-p0.md) 基础上继续优化。公共 API、默认 `RenderScale = 1`、DIP 模糊半径和圆角含义保持一致。

最终同条件 GPU 对照中，默认单面板额外耗时下降 **19–25%**，4/9 个面板下降约 **11% / 8%**；仅局部可见的大面板下降 **62–67%**。两值半径动画的降采样分配 **2800 → 464 B/帧（下降约 83%）**。完整可见、固定尺寸的降采样路径总体变化较小，没有宣称所有场景都提速。

- 全分辨率路径改用 Skia 原生 `SaveLayer` backdrop 滤镜，省去显式背景 crop snapshot 与回绘。局部坐标裁剪圆角后，在设备坐标中设置 sigma。原生合成存在细微色阶舍入差异。
- 降采样路径仅处理可见输出及 3×sigma 输入外扩，输入不受父容器输出裁剪限制；整数 clip 周围保留一物理像素，避免分数位置改变完整面板的采样网格。实际取样范围最终限制在源 Surface 内。
- 每个控件的不可变绘制操作复用引用计数资源：paint、圆角几何、两个精确 sigma 滤镜和工作 Surface。操作替换不修改旧操作的绘制参数，最后一个操作释放时销毁原生资源；弱 owner 不延长其寿命。
- 固定尺寸先创建精确大小的工作纹理，保留整图绘制的简单路径；发生尺寸增长时，再按 16 物理像素预留容量，减少后续半径/尺寸小幅变化时的重新创建。sigma 与绘制源范围始终使用实际采样尺寸，排除容量区。过大容量会在尺寸下降后缩小，GPU/CPU context、颜色类型或色彩空间变化时重建。
- 每帧仍采样当前背景，不缓存背景像素；不同控件不共享可变资源或采样图。重叠面板维持绘制顺序。工作 Surface 不可用时回退原生全分辨率 backdrop。

纹理预留通常使宽高各增加不足 16 像素；在连续缩小时可能暂留至实际尺寸的两倍（每维最小保留上限为 64）。这是容量复用的内存代价，不能将托管分配下降等同于原生/GPU 峰值内存下降。

## 未采用的路径

- 原生“降采样 → blur → 放大”滤镜链减少托管分配，但实际 GPU 耗时增加，尤其在 200% DPI 下，因此舍弃。
- 工作 Surface 直接 `Draw` 配合矩阵滤镜能少一次结果 Snapshot，每个面板节省约 104 B/帧，但部分降采样/多面板场景慢约 20–40%，因此保留结果 Snapshot。
- 始终预留纹理容量使部分固定尺寸 0.75 采样场景慢约 5–7%；最终调整为仅在增长时预留，静态面板保持精确纹理和整图绘制。
- 未增加跨面板背景共享、模糊半径量化或自动降低分辨率。这些改动会引入画面顺序或质量方面的新语义，需要独立设计和验证。

## 测量方法

- .NET 8 Release、Avalonia 12.1、桌面 Skia OpenGL，所有测量 Surface 均确认 texture-backed。未严格确认具体物理 GPU 适配器。
- 对照为本轮修改前的 P0 Release DLL，通过独立 AssemblyLoadContext 调用旧版实际绘制操作。按相同 `RenderScale` 对比，不混入降低分辨率的收益。
- 8 个场景 × 新旧各 3 个采样档位 × 3 轮 × 120 帧 = **17,280 个效果帧**，每帧各有紧邻无效果背景基线。每版每轮预热 20 帧；逐帧随机交错版本，场景组也随机排序。
- 使用 `GRContext.Flush(true, true)` 等待 GPU 完成；包括背景绘制、GPU/驱动/同步成本，不是纯 shader 时间或整页 FPS。不含 Border、布局、绑定、窗口呈现/VSync、前景渲染及其他线程分配。
- 每个面板拥有独立资源 owner；每帧参数替换先创建新操作，再释放旧操作，模拟保留式绘制场景替换。
- 动画案例在 sigma 12/12.5 两个精确值间交替。这会命中两项滤镜缓存；连续变化的半径仍需创建新滤镜，不能直接套用此案例的分配降幅。
- 局部可见案例为 1600×900 DIP 面板，clip 仅显示宽高各 25%，即面积 6.25%。
- 托管分配数据仅计当前测量线程。GPU cache 汇总是整个探针的末尾值，不能据此比较每版峰值内存。

## 画面与集成验收

- 最终全量测试 **212/212** 通过，其中 BackdropBlur **30 项**，新增父容器 clip 的外部输入、opacity group 回归；已有圆角、边框、DPI、背景刷新和零半径测试保留。
- **48 组真实 GPU 对照**，覆盖 sigma 4/12、DPI 100/125/200%、旋转 0/15°、分数位置、不对称圆角和采样 1/0.75/0.5/0.25。背景/透明度变化后恢复图像检查通过。
- 默认路径相对 P0 最大单通道差 **1 个色阶**，半透明整图平均差约 0.03。静态精确大小纹理的 36 组降采样对照逐像素一致。
- 每组另外通过同一个 owner 增大半径，触发纹理容量复用，再按旧操作原参数绘制。容量路径相对初始图像的最大色阶差为：0.75 档 11，0.5/0.25 档 7；对应整图平均差约 0.13/0.06/0.02。容量路径存在滤镜/采样的细微数值差异，因此不宣称动画与精确纹理逐像素一致。整图平均值包含未变化背景，不能代替局部视觉判断。
- 图像阈值收紧：允许 native 舍入时默认最大差 2、平均/opacity 差 ≤0.25；采样路径与纹理增长最大差 16、平均差 ≤1。没有关闭画面回归保护。
- 引用计数验收全部通过：旧操作参数不可变、共享资源复用、重复 Dispose、最后释放清空原生资源、Dispose 后不绘制、不能复活已释放资源、GPU→CPU→GPU 切换后 GPU 像素恢复一致。
- 实际 Demo 在 GPU 上完成采样 **1 → 0.5 → 0.75** 的双向绑定与圆角 **24 → 64 → 8** 切换，三张截图视觉检查通过：模糊可见、圆角更新、前景清晰。见 [Demo 半分辨率截图](../../artifacts/backdrop-blur-p1/demo-bin/demo-1.png)。
- net8.0/net10.0 控件、Demo、性能探针与 Demo 验收程序构建通过，无警告/错误。
