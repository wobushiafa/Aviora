# Contributing to Aviora

Thank you for taking the time to contribute.

## Development workflow

1. Discuss substantial API or visual changes in an issue before implementation.
2. Create a focused branch from the latest default branch.
3. Add or update tests and the demo for user-visible control changes.
4. Run `dotnet build` and `dotnet test` locally.
5. Open a pull request describing the behavior and any compatibility impact.

Keep public APIs documented and avoid unrelated formatting or refactoring in a
feature pull request.

By participating, you agree to follow the project
[Code of Conduct](CODE_OF_CONDUCT.md).
